# Geonosis Web

Geonosis IAM Server-in ucun landing page. Rust ile yazilmis open-source Identity & Access Management serverinin tanitim sayti.

## Tech Stack

- **Astro** - Static site generator
- **Tailwind CSS** - Styling
- **GSAP** - Scroll animasiyalari

## Commands

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Dependensileri yukluyur                     |
| `npm run dev`     | Local dev server qaldiriq (`localhost:4321`) |
| `npm run build`   | Production build (`./dist/`)                |
| `npm run preview` | Build-i localda preview edirsen             |
